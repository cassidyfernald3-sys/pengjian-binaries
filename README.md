# 朋间 · 安装包与更新公告

这个仓库只放可分发的安装包和更新公告，**不含源码**。朋间不上架任何商店，安装包以文件形式分发。

## 下载

安装包在 [Releases](../../releases) 里，文件名带版本与构建号：

```text
pengjian-flutter-windows-0.1.0-build4-unsigned-test.msi
```

`latest.json` 是客户端自动检查更新时读取的签名公告（Ed25519 签名），不需要手动下载。

## Windows 安装

1. **核对文件**（可选但建议）：

   ```powershell
   Get-FileHash -Algorithm SHA256 .\pengjian-flutter-windows-0.1.0-build4-unsigned-test.msi
   ```

   哈希与大小以 `latest.json` 里的 `sha256` / `bytes` 为准，对不上就不要安装。

2. **双击 MSI**。如果出现「Windows 已保护你的电脑」，点「更多信息」→「仍要运行」。内测包没有购买代码签名证书，这是预期提示。

3. 安装到 `%LOCALAPPDATA%\Pengjian Flutter Test`，开始菜单会出现「Pengjian Flutter Test」。与正式版 1.3.10 可同时安装。

## 升级

启动后如有新版本会弹窗提示：

- 「立即更新」→ 自动下载并在文件夹中选中安装包，**双击它覆盖安装**即可；
- 「取消」→ 本次跳过，下次启动再提示；
- 「跳过此版本」→ 该版本不再自动提示，仍可在「我的 → 检查更新」手动查看。

也可以直接下载新 MSI 双击安装，会覆盖升级，不需要先卸载。安装包只能升级、不能降级。

## 卸载

设置 → 应用 → 「Pengjian Flutter Test」→ 卸载，或执行：

```powershell
msiexec /x <安装包文件名>.msi
```

## 关于签名

内测包没有代码签名证书：

- 系统可能提示「未知发布者」或拦截一次，需要手动放行；
- 客户端只保证「下载到的文件与发布者签名的公告一致」（Ed25519 公告 + SHA-256 + 字节数），不保证安装包本身带系统信任的签名；
- 正式分发前会补代码签名证书，届时不再需要手动放行。
